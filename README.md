# Student Marks Analysis

A beginner-friendly Python data analysis project that analyzes student performance data using **Pandas** and **NumPy**.

## 📌 Project Overview

This project analyzes a Student Marks Dataset containing information about students, their background, test preparation, and scores in Math, Reading, and Writing.

The project demonstrates basic data analysis and data cleaning techniques using Python.

## 🎯 Objectives

* Load and analyze a CSV dataset.
* Check the dataset structure and information.
* Identify missing values.
* Clean missing data.
* Calculate average scores.
* Find maximum and minimum scores.
* Display the final analysis results using Pandas.

## 📊 Dataset

The dataset contains **1000 student records** and the following columns:

* Gender
* Race/Ethnicity
* Parental Level of Education
* Lunch
* Test Preparation Course
* Math Score
* Reading Score
* Writing Score

## 📈 Analysis Performed

The program performs the following analysis:

1. Loads the Student Marks CSV dataset.
2. Displays the first few records.
3. Checks dataset information.
4. Checks for missing values.
5. Cleans missing numerical and categorical values.
6. Calculates average scores.
7. Finds maximum scores.
8. Finds minimum scores.
9. Displays a final summary table.
